Ek original, professional aur advanced-level Security WebApp ka research aur planning karna. Isme security teams ko devices, alerts, incidents, vulnerabilities, identities, cloud resources aur security operations ko ek jagah samajhne aur manage karne ke liye interface diya jayega.

Dono reference products ke features license, subscription, tenant settings, product edition aur enabled services ke hisaab se badal sakte hain. Neeche diye gaye module groups research ko samajhne ke liye banaye gaye hain; inhe exact current menu labels ya dono products mein identical pages na samjhein.

## Suggested development approach

1. Pehle navigation, dashboard, alerts aur incidents ka complete frontend plan.
2. Phir endpoint, threat intelligence aur vulnerability workflows.
3. Uske baad identity, cloud, network aur SIEM capabilities.
4. Last mein automation, AI assistance, compliance aur administration.
5. Real security actions ko tabhi enable karna jab proper backend, authorization, audit logging aur security testing ready ho.
