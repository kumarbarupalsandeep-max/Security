## Research quality rules

- Official product documentation ko first preference di jayegi.
- Har important claim ke saath source link aur access / review date record ki jayegi.
- Product edition, subscription aur tenant settings ke hisaab se feature availability alag ho sakti hai.
- Unverified details ko fact ke roop mein nahi likha jayega.
- Apni explanation simple Hindi (Hinglish) mein original wording ke saath likhi jayegi.
- Third-party screenshots, logos, icons, proprietary text aur UI layouts copy karke repository mein nahi rakhe jayenge.
- Facts, observations aur analysis ko clearly alag rakha jayega.
